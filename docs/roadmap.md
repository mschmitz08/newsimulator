# Development Roadmap

## Version 0.1
Repository structure, editor automation, first explorable demonstration scene, first-person/free-flight camera, sunlight, sky-ready environment, procedural ground, roads, blocks, and placeholder massing buildings. Establish HDRP validation without pinning an incompatible Unity version.

## Version 0.2
Road network, sidewalks, curbs, intersections, lots, parking areas, lane markings, street hierarchy, and deterministic block generation.

## Version 0.3
Procedural buildings with facade variation, window layouts, roof types, setbacks, ground-floor treatments, and physically based material assignment.

## Version 0.4
HDRP glass, reflection probes, screen-space reflections, ray-tracing options where supported, interior approximation, emissive nighttime windows, and realistic exposure tuning.

## Version 0.5
Vegetation, streetlights, signs, street furniture, road markings, utility props, and richer environmental detail.

## Version 0.6
Time-of-day cycle, weather, wet surfaces, clouds, fog, atmosphere, and rain response.

## Version 0.7
LOD, occlusion, chunk boundaries, asynchronous loading preparation, profiling, and world-streaming architecture.

## Version 0.8+
Vehicles, traffic, pedestrians, geographic-data import, selected interiors, interaction, environmental audio, larger worlds, save data, and multiplayer architecture.

The order may change when a dependency makes another sequence technically safer.
