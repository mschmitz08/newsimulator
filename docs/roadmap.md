# Development Roadmap

## Version 0.1
Unreal C++ project structure, Visual Studio 2026 compatible engine baseline, free-flight inspection pawn, baseline Lumen/Nanite/Virtual Shadow Map settings, deterministic procedural city massing, documentation, and first local compile/play validation.

## Version 0.2
Road graph, lanes, sidewalks, curbs, intersections, medians, lots, parking, markings, signs, and PCG-assisted placement.

## Version 0.3
Procedural buildings with facade grammar, windows, roofs, setbacks, ground floors, material variation, Nanite-friendly modular assets, and selected interior approximation.

## Version 0.4
Production lighting, Lumen tuning, reflection quality, Substrate material stack, glass, emissive interiors, nighttime window variation, sky, atmosphere, clouds, and exposure.

## Version 0.5
Vegetation, streetlights, traffic signals, street furniture, utility props, signage, decals, litter, and environmental detail.

## Version 0.6
Time of day, weather, rain, wet surfaces, puddles, fog, wind, and dynamic environment response.

## Version 0.7
World Partition integration, HLOD strategy, profiling, streaming budgets, memory budgets, async generation/import, and scalable city expansion.

## Version 0.8+
Vehicles, traffic, pedestrians, geographic data import, selected interiors, interaction, audio, save data, multiplayer, and larger simulation systems.
